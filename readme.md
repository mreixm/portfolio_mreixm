## 🛠️ Tecnologias Utilizadas

O portfólio foi construído com foco em uma interface moderna, responsiva e funcional:

* **HTML5 / CSS3:** Estrutura e estilização com uso de variáveis CSS, Flexbox, Grid e animações personalizadas.
* **JavaScript:** Lógica para interatividade e manipulação do DOM.
* **EmailJS SDK:** Integração para recebimento de mensagens diretamente pelo formulário de contato, sem necessidade de um backend próprio para e-mail.
* **Devicon:** Conjunto de ícones para representar as tecnologias que domino.

---

## ✨ Funcionalidades

* **Design Moderno:** Estética "Glassmorphism" com fundos desfocados e gradientes.
* **Navegação Suave:** Scroll suave entre as seções (Início, Sobre, Projetos e Contato).
* **Formulário de Contato Funcional:** Validação de campos em tempo real e integração com o EmailJS para envio de mensagens.
* **Animações:** Efeito de flutuação na foto de perfil e transições suaves em botões e links.
* **Responsividade:** Adaptado para diferentes tamanhos de tela.

## 🚀 Como Executar o Projeto

1. **Clone o repositório:**
```bash
git clone https://github.com/seu-usuario/seu-repositorio.git

```


2. **Abra o arquivo `index.html**` em seu navegador preferido.

### ⚙️ Configuração do Formulário de Contato (EmailJS)

Para que o formulário funcione no seu ambiente, você precisará:

1. Criar uma conta no [EmailJS](https://www.emailjs.com/).
2. Configurar um **Email Service** e um **Email Template**.
3. Substituir as constantes no final do arquivo `index.html` pelas suas chaves:
```javascript
const EMAILJS_PUBLIC_KEY  = 'SUA_PUBLIC_KEY';
const EMAILJS_SERVICE_ID  = 'SEU_SERVICE_ID';
const EMAILJS_TEMPLATE_ID = 'SEU_TEMPLATE_ID';

```
